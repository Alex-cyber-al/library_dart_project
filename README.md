# Модульна контрольна робота №1

Практичні завдання виконувались у середовищі VS Code

# Хід роботи:

* **Завдання 1:** Реалізовано об'єктно-орієнтовану логіку на мові Dart. Створено класи Книги та Журналу, які наслідують загальний клас. Написано методи для пошуку за роком видання та знаходження найстарішого елемента бібліотеки.

# Запуск:

1. В терміналі проєкту запустити команду: dart run bin/main.dart
